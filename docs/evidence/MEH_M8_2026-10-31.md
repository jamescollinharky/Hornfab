## 2. The M2 testset was never executed, and did not pass as written

Three defects, all in the test, fixed in fork commits `93ef848` and `1efdc6f`; no property and no tolerance changed:

1. The wire blocks are nested per channel and per plane; `wire_rows` now flattens each channel before comparing.
2. Two comparisons broadcast `abs` over a `Vector{ComplexF64}` (`maximum(abs.(pair_forces))`), which errors.
3. The hand-built request forced `quadrature_order = 1, singular_order = 1`, coarser than the app's payload. On the
   4-triangle tetrahedron that destroys reciprocity. Measured through the real Python payload on the same fixture:
   **3.7e-4** reciprocity error at 100 Hz with the coarse orders and **2.2e-7** with the app's defaults; in-test the
   coarse orders gave **31.6 %**. Removing the two overrides (the app never sets them) is the fix; a finer fixture
   was not needed (n = 1, 2, 3 subdivisions all agree to ~1e-7 with the defaults).

  property of the 8,900-dof cap, not a bug; it must be stated wherever 8-12 kHz results are quoted.

## 6. Readiness link 2 - one multi-tag solve (MEASURED)

Through the app adapter (`BeatBackend("cuda")`, `SolveSpec(extra={"source_tags": [2, 10]})`, symmetry taken from the
mesh: `quadrants "1"`, `symmetry_plane "yz+xz"`). 5 frequencies, 360.5 s, VRAM baseline ~1.5 GB.

```
tags: (2, 10) cp: (5, 2, 2, 37) Z: (5, 2, 2)
areas: {2: 0.0010015, 10: 0.0047729}          # full-domain (quarter x 4)
legacy p_h == channel 0 p_h: True
readiness2 f=  200.0 force_recip=5.737e-05
readiness2 f=  500.0 force_recip=7.359e-05
readiness2 f= 1000.0 force_recip=1.045e-04
readiness2 f= 2000.0 force_recip=1.815e-04
readiness2 f= 4000.0 force_recip=3.217e-04
```

Pass: `channel_pressure` has the C4 shape, the force matrix (Z row-scaled by the full-domain tag area) is symmetric to
<= 3.2e-4, and the legacy fields are channel 0.

**An earlier run of this check failed at 22-38 %, and the cause was mine, not the solver's:** I drove the quarter mesh
with the fork directly and never set the symmetry flag, so a quarter shell was solved as a closed body. The app
adapter derives the flag from the mesh (`check_symmetry_pairing`), and with it the same check passes. Recorded here
because a 22-38 % reciprocity error would otherwise look like a solver defect.

The area-mean pressure matrix itself is NOT symmetric (it differs by the area ratio 4.77, i.e. 79 %), which is the
expected reading of C4: mean pressure = force / area, and only the force is reciprocal.
