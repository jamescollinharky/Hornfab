## Changed functions / files (fork)

Python:

- `hornlab_beat_bem/config.py` — `velocity_sources` accepts 1..8 tags; every
  tag keeps the real / unit-amplitude refusals; new `impedance_matrix: bool =
  False`; `source_tag` is the smallest tag; new `source_tags` sorted tuple.
- `hornlab_beat_bem/sweep.py::_request_payload` — with >= 2 tags adds
  `config["radiators"] = [{"name": "tagNNN", "tag": N, "channel": "tagNNN"}]`
  in sorted tag order and sends no `channels`; `tag_throat` stays the smallest
  tag; `impedance_matrix=True` adds `impedance_matrix_enabled: true`.
  One tag and no matrix adds no key.
- `hornlab_beat_bem/sweep.py::solve_frequencies` — checks every tag has area
  > 0; validates the returned zero-padded channel names; stacks all channel
  rows into `channel_pressure (F,C,P,A)` and `channel_sphere_pressure`; unpacks
  `impedance_matrix[j][i]` into `[f, i, j]`; fills `tag_areas_m2` with the
  full-domain area (reduced area × `_SYMMETRY_FACTOR`); legacy `pressure`,
  `spl`, sphere and impedance are channel 0 (smallest tag).
- `hornlab_beat_bem/result.py` — new `SolveResult` fields `channel_tags`,
  `channel_pressure`, `channel_sphere_pressure`, `impedance_matrix`,
  `tag_areas_m2`, all default `None`.
- `hornlab_beat_bem/capabilities.py` — sources count 1..8; per-tag mean
  pressures reported as reachable through `impedance_matrix`; capability
  schema 2 -> 3 because `sources.count.supported` changed from an int to a
  list and the per-tag entry changed shape.
- `VENDORING.md` — GPL-3 §5(a) notice for the new driver difference.

Julia (`hornlab_beat_bem/julia/BeatEngineDriver.jl`):

- New `impedance_matrix_for_channels`, placed immediately after
  `impedance_for_radiators`, using the task block unchanged except for the real
  helper names (see below). Row `j` is channel `j`'s boundary pressure; entry
  `i` is radiator `i`; each entry is `[Re(F)/2, -Im(F)/2]` with `F = 10 ×
  symmetry_factor × Σ p_avg·area`.
- The per-frequency result builds `impedance_matrix` only when
  `get_value(config, "impedance_matrix_enabled", false)`, and adds the
  `"impedance_matrix"` key to the result `Dict` only when it is non-`nothing`.
  With the flag absent the result keys are exactly the old ones.
- Legacy impedance with >= 2 channels now uses `channel_boundary_pressures[1]`
  (the smallest tag's channel, because `channel_names` is sorted) rather than
  the mixed sum, matching C4's "legacy fields = the channel of the smallest
  tag". With one channel it still uses `mixed_boundary_pressure`, so the
  default is unchanged.

Helper names: `radiator_owns_element`, `symmetry_reduction_factor`,
`mesh.physical_tags`, `mesh.faces`, `mesh.areas`, and `get_value` all exist in
the vendored code; nothing was invented. `symmetry_reduction_factor` comes
from `BeatEngineCore` and is already used unqualified by
`impedance_for_radiators`.

### Drive basis (the task's "confirm by reading the code")

`channel_boundary_pressures[j]` is built from `channel_unit_drives`, which
returns the tag's `velocity_offset_db` (0 dB in the M2 payload) and nothing
else; the flat-target correction is disabled because
`flat_target_normalization_enabled` is `false` in the request. It is therefore
already the field at unit drive and `impedance_matrix_for_channels` must not
divide by a drive. It does not.

### One radiator per tag

`impedance_matrix_for_channels` pushes one entry per `radiators` entry in the
request order. The M2 payload sends exactly one radiator per tag, in sorted tag
order, so matrix index `i` is tag `source_tags[i]`. If a later task puts
several radiators on one tag, the Python `[f, i, j]` unpacking would need a
tag-level sum; that is recorded here rather than silently assumed.

## Julia testsets — written, pending M8 (not executed here)

File: `hornlab_beat_bem/julia/tests/impedance_matrix_tests.jl`, included from
`hornlab_beat_bem/julia/tests/runtests.jl`. Run on the owner's box:

```powershell
julia -t auto --project=hornlab_beat_bem/julia hornlab_beat_bem/julia/tests/runtests.jl
```

It covers:

- helper superposition: `F(p1 + p2) = F(p1) + F(p2)` per radiator;
- single-tag parity: `impedance_matrix_for_channels(...)[1][1] ==
  impedance_for_radiators(...)[1]` at drive 1 and `symmetry_mode=:off`;
- reduced-vs-full symmetry: two mirrored triangle pairs integrated with
  `:off` on the full mesh and `:x` on the reduced mesh agree to 1e-6 relative;
- driver-level run on a regular two-tag tetrahedron: the two channel rows sum
  to one combined-channel row (pressure and force matrix), the 2x2 force matrix
  is reciprocal to < 1e-3 relative, and a one-tag request's matrix diagonal
  equals its legacy `impedance` to 1e-6.

No Julia syntax was executed in this task; the code is reviewed against the
neighbouring `impedance_for_radiators` / `pressure_for_drives` helpers.
